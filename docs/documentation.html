ELMS — Employee Lifecycle Management System

A full-stack HRIS covering the entire employee lifecycle from recruitment to confirmation. Built with PHP 8 + MySQL + vanilla JavaScript.

System Flow

Requisition → Candidates → Screening → Interview → Salary Proposal → Offer Approval → Offer Letter → Send Email → Candidate Response → Employee Creation → Salary Setup → Probation Appraisal → Confirmation Letter → Send Confirmation

Architecture

Backend

  • PHP 8.x with PDO/MySQL
  • RESTful JSON API endpoints
  • Transaction support for multi-step operations
  • Lifecycle logging via addCandidateLog()

Frontend

  • Vanilla JavaScript (no framework)
  • apiGet() / apiPost() from ajax/common.js
  • Quill.js rich-text editor for letters
  • Modal system, accordion, step wizard

Key Patterns

  • Shared endpoint: list_offers.php serves offer_letter, response, approval, and employee modules with query param filters
  • Template engine: templates/ajax/render.php resolves {{TAG}} placeholders via module-specific render files
  • Step wizard: employee/create.php uses a 6-step non-interactive stepper with auto-fill from candidate data
  • Salary auto-calc: Basic=57.1425%, House Rent=50% of Basic, Medical=10%, Conveyance=15%; tax fetched via AJAX

Module 1: Recruitment & Candidate Pipeline

Purpose

Manage job requisitions and track candidates through the hiring pipeline with full audit logging.

Workflow

HR creates Requisition (dept, designation, vacancies, salary range) ↓ Candidates apply / are added → auto-assigned status "Applied" (status_id=1) ↓ Each status change logged to candidate_logs (from_status → to_status, notes, created_by) ↓ candidates.status_id FK → candidate_statuses (Applied → Screened → Shortlisted → Interviewed → Selected → Offered → Hired)

Key Tables

Module 2: Screening & Interview

Workflow

HR screens candidate → result: Shortlisted / Rejected ↓ screening.match fields = Match / Partial / No Match Interview rounds added (1, 2, 3...) each with 4 score dimensions: Technical | Communication | Problem-Solving | Attitude ↓ is_final_round=1 marks last round → triggers decision ↓ decision: Shortlisted / Rejected / Selected Candidate status auto-updates via candidate_logs

Key Tables

TablePurpose
screeningsFK candidate_id, screened_by, rating, comm_score, exp/skill/edu_match, result
interview_logFK candidate_id, round, type, interviewer, 4 scores, rating, decision, is_final_round

Module 3: Salary Proposal

Workflow

HR creates proposal → enters Gross Salary ↓ auto-calc (see Salary Calculation section) Basic = Gross × 0.571425 House Rent = Basic × 0.5 Medical = Basic × 0.1 Conveyance = Basic × 0.15 Total Salary = Gross ↓ Gender-based tax fetched via AJAX → offer_management/ajax/get_taxinfo_ajx.php ↓ Total Payable = Total Salary − Personal PF − PF Deductible − Monthly Tax ↓ Stored as JSON in salary_breakdown column Status: Draft → Proposed → Pending_Approval → Approved → Finalized

Module 7: Employee Creation (6-Step Wizard)

Workflow

employee/list.php → shows Accepted offers ready for employee creation ↓ "Create Employee" employee/create.php?offer_id=X → 6-step wizard: Step 1: Personal Info (auto-filled from candidate) Step 2: Employment (Employment Type defaults to "Probationer") Step 3: Address (present + permanent) Step 4: Family & Nominee (spouse, children, nominee) Step 5: Other Details (location, working days, notes) Step 6: Salary Setup (interactive calculator) ↓ "Create Employee" 1. submitEmployee() → POST employee/ajax/save.php → INSERT personnel_basic_info (70+ fields, auto-generated PBI_CODE: EMP-00001) 2. submitSalaryData() → POST employee/ajax/save_salary.php → INSERT/UPDATE salary_info (50+ salary fields) 3. Redirect to employee/view.php?offer_id=X

Step 6: Salary Setup

Gross Salary (editable, oninput=calculateSalary()) ↓ auto-calc Basic = Gross × 0.571425 (readonly) House Rent = Basic × 0.5 (readonly) Medical = Basic × 0.1 (readonly) Conveyance = Basic × 0.15 (readonly) Total Salary = Gross (readonly) ↓ AJAX to get_taxinfo_ajx.php Monthly Income Tax (readonly, gender-aware) ↓ Total Payable = Total Salary − Personal PF − PF Deductible − Monthly Tax

Template Engine System

Architecture

letter_templates table stores HTML content with {{TAG}} placeholders ↓ templates/ajax/render.php receives { module, record_id, content } ↓ 1. SELECT render_file FROM template_modules WHERE module_name = :module 2. require_once render_file (e.g. templates/render/offer.php) 3. Call getTagMap(pdo, record_id) → Each render file queries DB, returns [ 'TAG' => 'value', ... ] 4. preg_replace /{{([A-Z_][A-Z0-9_]*)}}/ → value 5. Return { rendered_content, tag_count }

Salary Calculation Logic

Auto-Calculation Formula

ComponentFormulaExample (Gross=50,000)
Basic SalaryGross × 0.57142528,571.25
House RentBasic × 0.514,285.63
Medical AllowanceBasic × 0.12,857.13
Conveyance AllowanceBasic × 0.154,285.69
Total Salary= Gross50,000.00
Total PayableTotal Salary − Personal PF − PF Deductible − Monthly TaxVaries

Tax Calculation (Bangladesh FY 2024-25)

Endpoint: GET offer_management/ajax/get_taxinfo_ajx.php?gross_salary=X&basic_salary=Y&gender=male|female

Response

{ "success": true, "tax": 500.00, "annual_tax": 6000.00, "taxable_income": 60000.00 }

Logic

  • Annual taxable income = Gross × 12 − exemptions (10% of basic, 30% of basic, 10% of basic = 50% of basic total)
  • Minimum taxable: 3,50,000 BDT for males, 4,00,000 for females
  • Tax slabs: First 3.5L = 0%, 3.5-5L = 5%, 5-8L = 10%, 8-12L = 15%, 12-16L = 20%, 16-20L = 25%, 20L+ = 30%
  • Minimum annual tax: 5,000 BDT
  • Monthly tax = annual_tax / 12

Status State Machines

Candidate Status

Applied → Screened → Shortlisted
→ Interviewed → Selected → Offered → Hired
↗ Rejected (at any stage)

Offer Status

Pending → Approved → (letter flow)
       ↘ Rejected

Offer Response

Pending → Accepted
       ↘ Rejected

Offer Letter

Draft → Generated → Sent

Salary Proposal

Draft → Proposed → Pending_Approval
→ Approved → Finalized
↗ Rejected (can revise)

Probation Appraisal

Draft → In Progress → Completed
         ↘ Rejected
↗ Sent Back (to Draft)

Probation Workflow

Pending → Approved
       ↘ Rejected
       ↘ Sent Back

Confirmation Letter

Draft → Generated → Approved → Sent
                       ↘ Rejected
